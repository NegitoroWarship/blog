旅先でコードを書くなら、機材を増やすより、どこからでも復元できる環境をつくっておく方が安心できる。

## ローカルに抱え込まない

プロジェクトはGitへ、手順はREADMEへ、再現に必要な設定はリポジトリへ置く。端末固有の状態を少なくしておけば、別のPCでも迷わず作業を再開できる。

```sh
npm install
npm run dev
```

この二行で始められることは、小さなプロジェクトにとって大きな価値がある。

## 道具よりも復元性

高性能な端末より、壊れたときに戻せる仕組みを優先する。軽さとは、持ち物の重さだけでなく、環境を維持するための認知負荷の小ささでもある。
